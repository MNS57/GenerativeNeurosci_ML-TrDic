# GenerativeNeurosci_ML-TrDic

Code for reproducing a Transformer + Dice loss framework for bidirectional generation between unpaired in vitro and in vivo multineuronal spike trains.

Main script:
test_a2b_binary_step4_double_loop_v11_dictloss_invitromix2invivo_share.py

To run the analysis, download all files, place them in the same project folder, move into the `spike_tnb_200428` directory, and execute the main script. Please modify the data paths as needed for your local environment.
